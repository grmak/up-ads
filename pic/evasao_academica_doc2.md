# 📘 **Análise da Evasão Acadêmica em Universidade Particular Utilizando Técnicas de Machine Learning**

---

## 📌 1. Introdução

A evasão acadêmica é um problema recorrente em instituições de ensino superior, especialmente em universidades privadas, impactando tanto a sustentabilidade financeira das instituições quanto a trajetória educacional dos estudantes. A identificação precoce de fatores associados à evasão pode permitir intervenções mais eficazes.

Com o avanço das técnicas de análise de dados, métodos estatísticos e algoritmos de machine learning têm sido amplamente utilizados para prever comportamentos e apoiar a tomada de decisão. Nesse contexto, este estudo propõe a aplicação dessas técnicas para compreender e prever a evasão acadêmica.

---

## ❓ 2. Problema de Pesquisa

> Quais fatores influenciam a evasão acadêmica em uma universidade particular e como técnicas de machine learning podem ser utilizadas para prever esse fenômeno?

---

## 🎯 3. Objetivos

### 🎯 Objetivo Geral

Analisar e prever a evasão acadêmica em uma universidade particular utilizando técnicas de regressão e algoritmos de machine learning.

---

### 🎯 Objetivos Específicos

* Identificar variáveis relevantes associadas à evasão acadêmica
* Aplicar modelos estatísticos (regressão) para análise de relações entre variáveis
* Desenvolver modelos de classificação para previsão de evasão
* Comparar o desempenho de diferentes algoritmos de machine learning
* Interpretar os resultados e propor ações institucionais

---

## 🧠 4. Justificativa

A evasão acadêmica gera impactos significativos:

* Redução da receita institucional
* Descontinuidade na formação dos alunos
* Ineficiência no planejamento educacional

A utilização de técnicas de análise de dados permite:

* Identificar padrões ocultos
* Antecipar riscos
* Apoiar decisões estratégicas

Este estudo contribui tanto para a área acadêmica quanto para a gestão educacional.

---

## 🧪 5. Metodologia

### 📊 5.1 Tipo de Pesquisa

* Quantitativa
* Exploratória e descritiva

---

### 🗂️ 5.2 Coleta de Dados

Os dados podem incluir:

* Informações acadêmicas:

  * notas
  * frequência
  * reprovações
* Dados financeiros:

  * inadimplência
* Dados demográficos:

  * idade
  * gênero
* Dados de engajamento:

  * acesso a sistemas acadêmicos

---

### 🧹 5.3 Pré-processamento dos Dados

* Tratamento de valores ausentes
* Remoção de inconsistências
* Normalização de dados
* Codificação de variáveis categóricas

---

### 📈 5.4 Análise Exploratória (EDA)

* Estatísticas descritivas
* Correlação entre variáveis
* Visualização de dados

---

### 📉 5.5 Modelagem

#### 🔹 Modelos Estatísticos:

* Regressão Linear (para variáveis contínuas)
* Regressão Logística (para evasão binária)

#### 🔹 Modelos de Machine Learning:

* Árvore de Decisão
* Random Forest
* Gradient Boosting
* SVM (Support Vector Machine)

---

### 📏 5.6 Avaliação dos Modelos

* Acurácia
* Precisão
* Recall
* F1-Score
* ROC-AUC

---

### 🧠 5.7 Interpretação dos Resultados

* Identificação das variáveis mais relevantes
* Análise dos fatores de risco
* Proposição de ações preventivas

---

## ⚠️ 6. Limitações do Estudo

* Qualidade e disponibilidade dos dados
* Possíveis vieses nos dados históricos
* Generalização dos resultados

---

## 🧾 7. Resultados Esperados

* Identificação dos principais fatores de evasão
* Modelo preditivo com boa capacidade de generalização
* Apoio à tomada de decisão institucional
* Redução potencial da evasão
