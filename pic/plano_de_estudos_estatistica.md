# 📊 Matemática por Modelo de Machine Learning

| Modelo | Matemática necessária | Nível |
|--------|----------------------|------|
| Regressão logística | Função sigmoide, log-odds, máxima verossimilhança (intuição) | Médio |
| Árvore de decisão | Entropia, ganho de informação, índice Gini | Baixo |
| Random Forest | Bootstrap, agregação (média) | Baixo |
| XGBoost | Gradiente descendente, função de perda, regularização | Médio |
| SHAP | Shapley values (teoria dos jogos) | Médio-Alto |
